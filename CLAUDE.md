# BenchLedger
Electronics-lab project notebook. Stack: FastAPI + server-rendered pages + htmx (Python).
## Workflow rules
- Claude writes code; the owner audits, runs it, and handles ALL git commits and pushes.
- Never run git commit, git push, or change git config.
- Small, reviewable changes. Explain what changed and how to run/test it.
- Measurements must carry units and uncertainty; never silently drop either.
